CC VISUAL WEBSITE
==================
Open index.html in a browser to preview.

GitHub Pages:
1. Upload index.html to the root of your GitHub Pages repository.
2. Commit the file.
3. In Settings > Pages, select your main branch and root folder.
4. Save.

The page is responsive for desktop, tablet and mobile and uses the dark blue/neon cyan/pink/red visual style from the reference image.
